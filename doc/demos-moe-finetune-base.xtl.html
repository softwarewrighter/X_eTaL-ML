programdemos/moe-finetune/base.xtl

The base model every fine-tuning method starts from: a tiny mixture-of-experts trained in X_eTaL (train/base.xtl, fixed seeds) on tokens of 8 features in 4 kinds, each token's class (1 to 3) a rule of its kind's own. A shared layer z = tanh(S x), a router R on z, 4 experts at top 2, softmax over the classes. Its baseline: the accuracy on the training and the held-out tokens, kind by kind, and its routing with the router frozen: which experts each kind's tokens go to, how often each expert is chosen, the routing's entropy and balance. A method that changes the experts but not the router keeps this routing; one that trains the router can move it.
