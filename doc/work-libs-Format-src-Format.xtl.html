librarywork/libs/Format/src/Format.xtl

Format: number formatting -- fixed decimals, thousands separators, percentages, aligned columns, text tables. Import it with an alias of your choice: "f:" u_se< "Format". Put libs/Format/src on XETAL_PATH ("just path"); the reference is libs/Format/docs. Names with l: are exported; those under h: are private to this file.

X_eTaL's f_ormat has no width or precision yet (dyadic format is on its wish list): these build the text from the digits. A formatted list is a list of texts (Box Char), one per number, ready for f:c_olumn or f:t_able.
