librarylibs/Quant/src/Quant.xtl

Quant: weights in fewer bits: float rounding, integer and ternary quantization, a ternary layer as additions

Import it with an alias of your choice: "qz:" u_se< "Quant". Put libs/Quant/src on XETAL_PATH ("just path"); the reference is libs/Quant/docs. Names with l: are exported; h: names are private to this file.

Every format is simulated: the numbers stay Float, rounded as the format would store them, so a network runs unchanged on the rounded weights. A scale or a threshold is a number for the whole array, or an array shaped as the weights (per layer, per row: the caller chooses).
