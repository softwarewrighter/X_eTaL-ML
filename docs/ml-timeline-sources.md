# ML timeline: sources

Each event in `timeline/data/timeline.json`, by year, with where its
date, authors and title come from. A paper's source is the paper itself
(its DOI or arXiv record, the date of publication or of the first arXiv
version); a milestone's is a reference page. The history step adds the
rest of the events from `docs/ml-timeline-plan.md`, each checked, and a
test that every event is listed here.
