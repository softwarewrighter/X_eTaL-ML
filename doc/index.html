Files

  • library libs/Attention/src/Attention.xtl: Attention: scaled dot-product scores, masked softmax weights, causal masks, a head
  • library libs/NN/src/NN.xtl: NN: neural-network building blocks -- activations, softmax by row, dense layers, one-hot, loss, accuracy
  • library libs/Conv/src/Conv.xtl: Conv: convolution for a batch of pictures: 3 x 3 windows, filters as one matrix product, max-pooling, and their backward passes
  • library libs/Embed/src/Embed.xtl: Embed: word embeddings from counts: co-occurrence, PPMI, a fixed projection, cosine neighbors
  • library work/libs/Lists/src/Lists.xtl: Lists: list functions -- differences, windows, moving means, run lengths, chunks, shifts, interleaving, binary search, raze. Import it with an alias of your choice: "li:" u_se< "Lists". Put libs/Lists/src on XETAL_PATH ("just path"); the reference is libs/Lists/docs. Names with l: are exported; those under h: are private to this file.
  • system macros std/System.xtlm: The system macros (lang-choices MC18, MC19, MC24), loaded before every file with no import and no alias: each is called unprefixed, as "c" i_f< "a; b". A macro is a function of the source text on each side of its call; the text it gives replaces the call. @ on a side means the macro takes nothing there (MC22). What only the compiler knows comes from hooks (MC20), usable only in a macro body.
  • library libs/Learn/src/Learn.xtl: Learn: classic machine learning: k-means, k nearest neighbors, PCA, logistic regression
  • library libs/Norm/src/Norm.xtl: Norm: normalizing each row: layer norm and RMS norm, with a gain and a bias
  • library libs/Optim/src/Optim.xtl: Optim: optimizers as steps: gradient descent and Adam on a weight array and its averages
  • library libs/Quant/src/Quant.xtl: Quant: weights in fewer bits: float rounding, integer and ternary quantization, a ternary layer as additions
  • library libs/Sample/src/Sample.xtl: Sample: choosing the next token from scores: greedy, temperature, top-k, drawing by given uniform numbers
  • macro library libs/Net/src/Net.xtlm: Net: a network written as one line -- its layer sizes and activations become ordinary NN calls
  • program libs/Attention/demos/previous.xtl: A head that looks one token back: each token's key says where it is, each query asks for the place before its own, so under the causal mask every token takes on its predecessor's value. Run with "just demo-lib Attention previous".
  • program libs/Conv/demos/edges.xtl: Conv on one small picture: a square, two edge filters, ReLU and pooling, drawn. Run with "just demo-lib Conv edges".
  • program libs/Embed/demos/pets.xtl: Embed on a corpus small enough to read: twelve sentences about pets and food. Run with "just demo-lib Embed pets".
  • program libs/Learn/demos/blobs.xtl: Learn's four models on one set of points: three blobs of 20 (around 0 0, 6 6 and 0 6, a fixed ripple instead of chance). k-means finds them without their labels; kNN and logistic regression learn them from their labels; PCA finds the direction they spread along most. Run with "just demo-lib Learn blobs".
  • program libs/Net/demos/train-xor.xtl: XOR learned, the network and its training each written as one line: t_rain< writes the training step (backpropagation and Adam) from the same spec n_etwork< reads. Small random weights at the start. Run with "just demo-lib Net train-xor"; see what was written with "just expand-lib Net train-xor".
  • program libs/Net/demos/xor.xtl: XOR, the network written as one line. NN's own demo builds the same two layers by hand; here the spec "2 2 relu 2 softmax" is the network, and xetal expand shows the function the macro wrote. Run with "just demo-lib Net xor"; see it with "just expand-lib Net xor".
  • program libs/NN/demos/xor.xtl: XOR by a two-layer network with hand-set weights: no straight line separates XOR's classes, but one hidden ReLU layer does. Every layer is one nn:d_ense on the whole batch of four points at once. Run with "just demo-lib NN xor".
  • program libs/Norm/demos/rows.xtl: Two rows on very different scales, made alike by layer norm and by RMS norm. Run with "just demo-lib Norm rows".
  • program libs/Optim/demos/bowl.xtl: Gradient descent and Adam on a long narrow bowl, where the two directions want very different step sizes. Run with "just demo-lib Optim bowl".
  • program libs/Quant/demos/formats.xtl: One weight matrix stored five ways, and how far each moves a layer's output. Run with "just demo-lib Quant formats".
  • program libs/Sample/demos/next.xtl: Choosing the next word from a model's scores over six words: the greedy choice, the probabilities at three temperatures, top-2, and twenty draws (r_oll!, seeded). Run with "just demo-lib Sample next".
  • program demos/attention/attention.xtl: Attention as array algebra: every token's query meets every token's key in one matrix product, S = Q K^T / sqrt d; softmax turns each row into weights; the output is the weighted sum of the values, Y = A V. One head, hand-set so that a word looks for what it can describe.
  • program demos/backprop/backprop.xtl: One step of training, every array shown: a small network (2 inputs, 4 tanh units, softmax over 3 classes) on six points of a spiral. The forward pass, the loss, each layer's gradient as one expression, the step; then every gradient checked against a finite difference.
  • program demos/cnn-backprop/cnn-backprop.xtl: Training a tiny convolutional network in X_eTaL, from random weights, on 600 handwritten digits: 28 x 28 -> 8 filters of 3 x 3 -> ReLU -> 2 x 2 max-pooling -> dense -> softmax, as cnn-digits reads them. The backward pass undoes each stage in turn: the dense layer, the pooling (each block's gradient to its largest item), the ReLU and the convolution, each a few array expressions over the whole batch; it is checked against finite differences. Adam moves the weights, 20 digits a step, and p_ower repeats the step.
  • program demos/cnn-digits/batch.xtl: The digit reader over a batch: the first 1,000 MNIST test digits as one batch through the Conv library (the windows of every picture, one product for the batch, the pooling), then the dense layer; how many digits it reads right, the count the trainer's Rust forward pass gives from the same pixels. The batch run for a GPU (docs/gpu-asks.md); cnn-digits.xtl is the lesson, a picture at a time.
  • program demos/cnn-digits/cnn-digits.xtl: A tiny convolutional network reads a handwritten digit: 28 x 28 -> 8 filters of 3 x 3 -> ReLU -> 2 x 2 max-pooling -> dense -> softmax. The convolution is the picture's nine shifted copies times the filters: one matrix product. Trained offline on MNIST (97.82% of the 10,000 test digits right); just cnn-train writes data/.
  • program demos/diffusion/diffusion.xtl: A learned denoiser: pictures from noise, step by step. The pictures are 10 x 10, one of three shapes (a disk, a hollow square, a cross) at some place, a pixel -1 off or 1 on. A small convolutional network (train/) was trained to see the clean picture in a noisy one at ten levels of noise. Sampling runs it backward: from a picture of pure noise, each step predicts the clean picture, infers the noise that must have been added, and steps down one level (DDIM, no new noise), so the picture that comes out depends only on the noise that went in.
  • program demos/embedding-explorer/embedding-explorer.xtl: Word embeddings from counts, and a 3-D look at them: 4,000 short sentences over 70 words, each word's embedding a row of 64 numbers made from which words occur near it (the Embed library: counts, PPMI, a fixed projection). Words used alike point alike: the animals together, the foods, the colors, the numbers, the places. Learn's PCA turns the 64 dimensions into the 3 that spread the words most, for a cloud to look at.
  • library work/libs/Strings/src/Strings.xtl: Strings: text functions -- case, trimming, words, split and join, search, replace, padding. Import it with an alias of your choice: "t:" u_se< "Strings". Put libs/Strings/src on XETAL_PATH ("just path"); the reference is libs/Strings/docs. Names with l: are exported; those under h: are private to this file.
  • program demos/k-means/k-means.xtl: k-means, step by step: 300 points in five blobs, five centers. Each step gives every point the nearest center, then moves each center to the mean of its points (the Learn library's k_step: a few array expressions over all the points at once). From a poor start, five points of one blob, the centers travel across the plane to the blobs; from Learn's farthest-first start they barely need to.
  • program demos/micro-gpt/batch.xtl: The tiny GPT over a batch of names: the first 1,000 names of its training file (makemore's names.txt) scored by the forward pass of micro-gpt.xtl, a name per call under its causal mask; the mean loss per token (the cross-entropy the trainer reports) and how many next letters it predicts right, both as the trainer's Rust model gives them. The batch run for a GPU (docs/gpu-asks.md): a thousand calls of one forward pass, the token ids all that goes in.
  • program demos/micro-gpt/micro-gpt.xtl: A tiny GPT in X_eTaL: Karpathy's microgpt (1 layer, 16 numbers wide, 4 attention heads, 4,192 weights), trained offline on 32,033 baby names, inventing new ones a letter at a time. The forward pass reads a whole name at once under a causal mask, on the Norm, Attention and Sample libraries; it gives the same scores as the Rust model it was trained in.
  • program demos/moe-router/moe-router.xtl: A mixture-of-experts router: each token of a sentence is scored against 16 experts by one matrix product, the scores become probabilities (softmax), each token keeps its two most likely experts (top-2), and their probabilities, renormalized, are the gates. The experts' load is how many tokens each one got.
  • program demos/net-macro/net-macro.xtl: Three networks for one task (which of three spiral arms is a point on?), each described once, by one line: the Net macro library turns a spec, sizes and activations, into the loading of the weights and an ordinary function of NN calls before the program is compiled. xetal expand shows what it wrote.
  • program demos/net-macro/train-it.xtl: Training a network from its one-line spec: the Net macro library writes, from "2 16 relu 16 relu 3 softmax", the network's backward pass and an Adam step (net:t_rain<) and the starting state (net:s_tate<); p_ower repeats the step. The task is net-macro's: which of three spiral arms is a point on? Here the 300 training points are made in X_eTaL, and the weights start small and random.
  • program demos/ternary-net/ternary-net.xtl: A 1.58-bit network: a tiny classifier (which of three spiral arms a point is on, 2 -> 16 -> 16 -> 3) run with its weights stored four ways: 32-bit and 16-bit floats (simulated by rounding), 8-bit integers, and ternary -1 / 0 / +1 (log2 3 = 1.58 bits each), where a layer is additions and subtractions of its inputs and one scale. The same points go through all four; the measures compare them.
  • program demos/train-live/train-live.xtl: Training in X_eTaL: a network (2 inputs, 16 tanh units, softmax over 3) learns which of three spiral arms a point is on. The points are made here; the backward pass is the backprop microscope's; Adam, written out, moves the weights; p_ower repeats the step.
  • program demos/world-model/world-model.xtl: A tiny world model: a network that has watched a ball bounce in a box predicts the next frame from the last three. The world is a 2 x 2 ball in a 12 x 12 box, moving 1 or 2 cells a step on each axis and bouncing off the walls: 1,936 states in all. The network (432 pixels in, 64 ReLU units, 144 pixels out) was trained offline on four fifths of them (train/); the other fifth it never saw. Here it predicts the next frame of every state at once, as one batch, then dreams: fed its own predictions, it plays the ball forward on its own.
