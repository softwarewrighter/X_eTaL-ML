programdemos/cnn-backprop/cnn-backprop.xtl

Training a tiny convolutional network in X_eTaL, from random weights, on 600 handwritten digits: 28 x 28 -> 8 filters of 3 x 3 -> ReLU -> 2 x 2 max-pooling -> dense -> softmax, as cnn-digits reads them. The backward pass undoes each stage in turn: the dense layer, the pooling (each block's gradient to its largest item), the ReLU and the convolution, each a few array expressions over the whole batch; it is checked against finite differences. Adam moves the weights, 20 digits a step, and p_ower repeats the step.
