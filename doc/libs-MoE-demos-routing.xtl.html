programlibs/MoE/demos/routing.xtl

A mixture-of-experts layer on 32 tokens: 8 experts, each an 8 x 8 projection adapted at rank 2, the top 2 chosen per token. How the tokens spread over the experts, the sparse layer against the dense reference, and what running only the chosen experts saves. Run with "just demo-lib MoE routing".
