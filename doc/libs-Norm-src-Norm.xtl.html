librarylibs/Norm/src/Norm.xtl

Norm: normalizing each row: layer norm and RMS norm, with a gain and a bias

Import it with an alias of your choice: "nm:" u_se< "Norm". Put libs/Norm/src on XETAL_PATH ("just path"); the reference is libs/Norm/docs. Names with l: are exported; h: names are private to this file.

Rows are examples (or tokens); each is normalized along its own numbers. A gain and a bias have one number per column and travel as a pair, (g, b); eps (0.00001) keeps a constant row from dividing by 0, so results are a hair from the exact ones (-0.99999 for -1).
