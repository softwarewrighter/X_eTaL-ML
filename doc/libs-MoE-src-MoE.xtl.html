librarylibs/MoE/src/MoE.xtl

MoE: mixture-of-experts layers: router scores, top-k gates, experts as adapted projections, the sparse combine, gradients and routing statistics

Import it with an alias of your choice: "moe:" u_se< "MoE". Put libs/MoE/src on XETAL_PATH ("just path"); the reference is libs/MoE/docs. Names with l: are exported; h: names are private to this file.

Tokens are columns, as in the LoRA library: x is n x N, N tokens of n numbers. The router R (E x n) scores each token against E experts; each token's scores become probabilities over the experts (a column's softmax), and its k most likely experts are kept, their probabilities renormalized over those k: the gates G (E x N, 0 where an expert is not chosen). An expert here is an adapted projection, W_e x + s B_e (A_e x) (the LoRA library's layer); the experts are stacked, (Ws, As, Bs, s): Ws E x m x n, As E x r x n, Bs E x m x r, one scale s. The layer is y = sum over the chosen e of G_e (W_e x + s B_e (A_e x)), each token through its k experts only. Every function takes its data on the right, so each can be a Flow stage.
