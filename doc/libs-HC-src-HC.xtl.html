librarylibs/HC/src/HC.xtl

HC: Hyper-Connections and mHC: streams mixed by tables, the Sinkhorn projection, the layer and its gradients, the gains by depth, the input-dependent tables Import it with an alias of your choice: "hc:" u_se< "HC". Put libs/HC/src on XETAL_PATH ("just path"); the reference is libs/HC/docs. Names with l: are exported; the others are private to this file.

Hyper-Connections (Zhu et al., arXiv 2409.19606) widen the residual stream into S streams mixed by small tables; mHC (Xie et al., DeepSeek-AI, arXiv 2512.24880) projects the table that carries the state onto the doubly stochastic matrices (Sinkhorn-Knopp), so its gain stays bounded at any depth. A stream state X is S x N, a stream a row (N the width, or B times the width for a batch, examples side by side); H_res is S x S; H_post a list of S; H_pre an S x S table (the block's input the mean over streams of H_pre X, as the static form of the mHC-poc Python has it) or a list of S (the block's input H_pre X, as the paper's eq. 3 and hc:d_ynamic give it). Asked by X_eTaL-fine-tuning (FM13), whose depth track wrote all of it out.
