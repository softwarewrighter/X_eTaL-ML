librarylibs/Learn/src/Learn.xtl

Learn: classic machine learning: k-means, k nearest neighbors, PCA, logistic regression

Import it with an alias of your choice: "ml:" u_se< "Learn". Put libs/Learn/src on XETAL_PATH ("just path"); the reference is libs/Learn/docs. Names with l: are exported; h: names are private to this file.

After APLearn's list (k-means, kNN, PCA, logistic regression), each a fit and a predict: the data X is a matrix, one example per row; labels count from 1. Every model is whole-array arithmetic, and an iterative fit is a step repeated by p_ower.

  mu ← ('+ r̲/₁ X) ÷ f̲loat t̲ally X

  S0 ← ((o̲\ Z) '+ '× i̲nner Z) ÷ f̲loat t̲ally X
  u0 ← 1.0 + 0.1 × f̲loat o̲ffsets d
  (_, V, ev, _) ← n '{ (S, V, ev, i) →
    v ← 200 '{ u → w ← S '+ '× i̲nner u◆ w ÷ ('+ r̲/ w × w) ^ 0.5 } p̲ower u0
    v1 ← v × 1.0 − 2.0 × f̲loat 0.0 > '+ r̲/ v
    lam ← '+ r̲/ v1 × S '+ '× i̲nner v1
