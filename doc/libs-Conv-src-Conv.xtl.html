librarylibs/Conv/src/Conv.xtl

Conv: convolution for a batch of pictures: 3 x 3 windows, filters as one matrix product, max-pooling, and their backward passes

Import it with an alias of your choice: "cv:" u_se< "Conv". Put libs/Conv/src on XETAL_PATH ("just path"); the reference is libs/Conv/docs. Names with l: are exported; h: names are private to this file.

A batch is n pictures of h x w (n x h x w); a picture alone is a batch of one. Filters K are f rows of 9 (a 3 x 3 filter row by row) with biases B (f); maps are n x f x (h - 2) x (w - 2) (valid convolution), pooled by 2 x 2 blocks to half each side.
