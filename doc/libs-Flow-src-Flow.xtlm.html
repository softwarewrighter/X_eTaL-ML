macro librarylibs/Flow/src/Flow.xtlm

Flow: ML data flow written left to right, |> between stages -- each stage becomes one line of X_eTaL

Import it with an alias of your choice: "flow:" u_se< "Flow" (flow:p_ipe<). Put libs/Flow/src on XETAL_PATH ("just path"); the reference is libs/Flow/docs. Names with m: are macros; those under h: are private to this file.

A macro is a function from the source text written left and right of its call to the source that replaces the call, before the program is compiled (X_eTaL MC10); xetal expand FILE shows the result. The pipeline was decided in X_eTaL (D155, its docs/spatial.md, "Pipelines") and is built here (docs/pipeline-macro.md). Its reader uses all of its text or refuses it: a stage the grammar does not know is a compile-time error naming the text, never a wrong answer.

ᵐp̲ipe< : Unit -> Char -> Char

macro · line 37 · binds it

The value of a pipeline: the data, then each stage in turn, |> between them. A stage is a function (act:r_elu, [f_ g_], '{ x -> ... }), applied to the previous value, or an expression naming the previous value it (W nn:d_ense it; the order is written, never guessed). "$name" at a stage's end names its value for the later stages, the $ touching the name ("$(Q, K, V)" takes a tuple apart, as X_eTaL's S14 label is written and drawn); " [N O]" after the name is the shape the value must have, checked when the program runs (error[shape], naming the stage, its shape and the one expected). The left side is @; the right is a code string c"...", drawn as X_eTaL (|> and $ as triangles), and may put one stage per line; a plain or raw string reads the same.

      "flow:" u̲se< "Flow"
      x ← f̲loat 1 2 3 4
      @ ᶠˡᵒʷp̲ipe< c"x ▹s ▷ 2 × it ▷ it + s"
3.0 6.0 9.0 12.0
