programdemos/cnn-digits/batch.xtl

The digit reader over a batch: the first 1,000 MNIST test digits as one batch through the Conv library (the windows of every picture, one product for the batch, the pooling), then the dense layer; how many digits it reads right, the count the trainer's Rust forward pass gives from the same pixels. The batch run for a GPU (docs/gpu-asks.md); cnn-digits.xtl is the lesson, a picture at a time.
