librarywork/libs/Lists/src/Lists.xtl

Lists: list functions -- differences, windows, moving means, run lengths, chunks, shifts, interleaving, binary search, raze. Import it with an alias of your choice: "li:" u_se< "Lists". Put libs/Lists/src on XETAL_PATH ("just path"); the reference is libs/Lists/docs. Names with l: are exported; those under h: are private to this file.

Counts and sizes go on the left, the list on the right, as for the built-ins: 3 li:w_indows v.
