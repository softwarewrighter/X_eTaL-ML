librarylibs/Sample/src/Sample.xtl

Sample: choosing the next token from scores: greedy, temperature, top-k, drawing by given uniform numbers

Import it with an alias of your choice: "sm:" u_se< "Sample". Put libs/Sample/src on XETAL_PATH ("just path"); the reference is libs/Sample/docs. Names with l: are exported; h: names are private to this file.

Scores (logits) are a row per position, a column per token; tokens count from 1. The library draws no chance itself: a draw takes uniform numbers in 0 .. 1 from the caller (r_oll!, seeded, or any other source), so the same numbers give the same tokens.

  rows ← m r̲eshape p
  ⍝# Each row's k-th largest: its largest taken and shifted below the
  ⍝# rest, k times (X_eTaL has no grade along a row yet). The shift is
  ⍝# finite, 1 + the range of the values, so it runs in 32-bit floats
